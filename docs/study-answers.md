# B3-1 학습 문제 정답·해설

1. **GitHub는 코드 보관·버전 관리**, 배포는 사용자가 접속할 수 있도록 웹서버/호스팅 환경에서 파일과 서비스를 제공하는 작업입니다.
2. **VPC는 큰 네트워크**, 서브넷은 그 안에서 분할한 주소 구역입니다. 하나의 VPC에 여러 서브넷을 만들 수 있습니다.
3. **80은 HTTP**, **443은 HTTPS**, **22는 SSH 원격 접속**에서 주로 쓰는 기본 포트입니다.
4. localhost는 서버 내부 요청이므로 내부 웹서버가 정상이어도 외부 IP, 보안 그룹, 라우팅이나 방화벽 설정 때문에 외부에서 접근하지 못할 수 있습니다.
5. **Nginx 설정 구문과 참조 파일 등에 대한 검사에 통과**했다는 뜻입니다. 실제 외부 접속 성공까지 보장하지 않습니다.
6. `proxy_pass`는 Nginx가 받은 요청을 지정한 다른 서버에 전달합니다.
7. 프록시가 전달할 대상인 컨테이너가 응답하지 못해 Nginx가 유효한 응답을 받지 못할 수 있습니다. 다른 원인으로도 502가 발생할 수 있습니다.
8. 삭제되지 않은 EBS, 탄력적 IP, 기타 리소스, 사용량 정산 등이 남아 있을 수 있으므로 Billing과 리소스 목록을 확인합니다.
