# B3-1 실습 IAM 계정 권한 거부 검증 — 2026-11-22 19:32 KST

> 아래 기록은 사용자 제공 AWS IAM 콘솔 스크린샷의 실제 문구를 바탕으로 작성한 텍스트 증빙입니다. 전체 계정 번호는 공개 문서에서 생략했습니다.

## 검증 대상과 결과

- AWS IAM 실습 사용자: `b31-learner`
- 방문 페이지: IAM > 정책(Policies)
- 요청 작업(Action): `iam:ListPolicies`
- AWS 화면 오류: **`iam:ListPolicies에 대한 액세스 거부됨`**
- 상세 원인: **`no identity-based policy allows the action`**
- 결과: 현재 IAM 사용자로는 계정의 전체 IAM 정책 목록을 조회할 수 없음을 직접 확인했습니다.

## 무엇을 입증하는가

IAM 권한은 AWS 콘솔과 API에서 어떤 관리 작업을 수행할 수 있는지를 제어합니다. 실습용 `b31-learner`로 `iam:ListPolicies`를 시도했을 때 권한 거부가 발생한 것은 해당 작업을 허용할 권한이 부여되지 않았다는 직접적인 관찰 근거입니다. IAM 관리 권한을 무조건 제공하지 않는 **최소 권한 설계의 한 사례**로 설명할 수 있습니다.

## 이 화면만으로 확인할 수 없는 것

- `B31PracticePolicy`의 전체 JSON 내용, 허용되는 개별 AWS API 작업 목록
- 실습과 무관한 S3/RDS 등에 대한 권한 여부
- 모든 AWS 서비스에 최소 권한이 완전히 적용되어 있는지 여부

따라서 이 화면을 모든 권한의 완전한 검증이나 정책 JSON 전체 확인으로 표현하지 않습니다. 관리자 권한으로 정책 세부 내용을 조회할 때 허용된 작업 범위 및 실제 연결 대상을 추가 기록할 수 있습니다.

## 보안 그룹과의 구별

- **IAM 정책**: AWS 제어 영역(콘솔·API)의 사용자 작업 권한
- **EC2 Security Group**: EC2 네트워크에 들어오는/나가는 트래픽 제어
- 예: `iam:ListPolicies` 거부와 SSH 22의 특정 출처 허용은 서로 다른 계층에서 적용되는 제한입니다.
