# 실습 리소스 정리 체크리스트

실습 중 만든 리소스의 ID와 정리 시각을 기록합니다. 접속 화면과 출력 증빙을 저장한 뒤 해당 리소스를 정리하고 확인한 항목에 표시합니다.

| 확인 | 항목 | 완료 확인 기준 |
| --- | --- | --- |
| ☐ | EC2 | 실습 인스턴스 `Terminated` 확인 |
| ☐ | EBS | 실습 인스턴스에 연결했거나 남아 있는 실습 볼륨 삭제 확인 |
| ☐ | Elastic IP | 실습 중 할당했다면 연결 해제 후 릴리스 확인 |
| ☐ | 추가 리소스 | 실습 중 만든 NAT Gateway·로드 밸런서·RDS가 있다면 해당 리소스 삭제 확인 |
| ☐ | 보안 그룹 | 실습 전용 Security Group 삭제 확인 |
| ☐ | Route Table과 서브넷 | 실습용 연결을 해제한 뒤 라우팅 테이블·서브넷 삭제 확인 |
| ☐ | Internet Gateway와 VPC | Internet Gateway 연결 해제와 삭제 후 실습용 VPC 삭제 확인 |
| ☐ | DNS | HTTPS 실습에 사용한 A 레코드 정리 확인 |
| ☐ | Billing | 실습 리소스 목록과 Billing 화면에서 정리 결과 점검 |
